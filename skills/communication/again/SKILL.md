---
name: again
description: Say the last message again in plain English, keeping every name and number exact.
disable-model-invocation: true
---

Restate your last message plainly. Short sentences, everyday words, like one human
talking to another.

Keep every name the source used, exactly: paths, line numbers, functions,
commands, error strings, issue numbers, commit hashes, quoted evidence, and every
number with its unit. Never describe by role something the source named. Cut
explanation before you cut a name.

Add nothing the source did not say. No invented number, option, recommendation, or
hedge about what was verified.
