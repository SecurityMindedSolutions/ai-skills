Acme Portal is a small multi-tenant document portal (fictional): a Flask JSON API under api/, a React front end under web/, Terraform under infra/ and GitHub Actions under .github/. Handlers must apply their own authentication with the `require_login` decorator; there is no global gate. Documents belong to organizations and every read or write of a document should be scoped to the caller's organization (`current_org()`). Files are stored under STORAGE_ROOT on disk, one folder per organization. The web framework caps request bodies at 16 MB. Environment variables are trusted configuration; secrets are meant to come from the environment or a secret manager. The uploads bucket holds customer files and must not be public. The API server is internet-facing.
