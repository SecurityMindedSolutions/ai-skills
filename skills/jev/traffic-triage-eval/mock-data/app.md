A trust-center SaaS for startups. Two hosts: `app.example-trust.io` serves a React single-page admin app from `/` with static assets under `/assets/`, `/favicon.ico` and `/logo.svg`, and a JSON API under `/api/v1/`: `/api/v1/auth/*` (sign-in, MFA, `user_info`, OAuth authorize/token, and `/api/v1/auth/oauth/register`, an unauthenticated client-registration endpoint), `/api/v1/tenants/<slug>/*` (documents, pages, settings, members, audit - all require a session), `/api/v1/tenant_admin/health` (scheduler health check), and `/mcp` for MCP clients. `trust.example-trust.io` serves public trust pages at `/<tenant-slug>`, `/<slug>/documents`, `/<slug>/faq`, and the public read API `/api/v1/trust/pages` and `/api/v1/trust/documents`, both taking a `tenant_id` query parameter of the form `t_xxxxx`. The site publishes `/robots.txt`, `/sitemap.xml` and `/.well-known/security.txt`. It runs no WordPress, PHP, Java application server, database admin panel, or other CMS, and there is no `/admin` route.
